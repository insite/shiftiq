# InSite.UI: Web user interface

ASP.NET WebForms application targeting .NET Framework 4.8. Hosts the browser-facing UI, the Web API surface, and the React-rendered portions of the site.

## Subfolders

### Api

Web API controllers exposed to client-side code and external integrations.

### React

React applications and supporting assets rendered inside WebForms pages.

### UI

WebForms pages (`.aspx`), user controls (`.ascx`), and master pages organized by feature area (Admin, CMDS, Layout).

### Web

Application-level web infrastructure: routing, HTTP modules, handlers.
